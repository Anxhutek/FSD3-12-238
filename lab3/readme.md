# HTTP Module

The **HTTP Module** is a built-in Node.js module that allows developers to create **web servers and web clients** without installing any external packages.

It is one of the most important modules in Node.js, originally designed for building **scalable network applications and web servers**.0
**[npm= node package manager]**
## Key Features

1. **Create Web Servers**
2. **Handle Client Requests**
3. **Build REST APIs**
4. **Non-Blocking I/O**
5. **Foundation of Express.js**

## http status codes

- 200 -> OK
- 201 -> Created
- 400 -> Bad Request
- 401 -> unauthorized
- 403 -> forbidden
- 404 ->not found
- 500 -> Internal server error


### Server can send to the client
